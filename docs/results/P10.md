# P10 — OCAM paper model: SEM, Siamese, Chamfer loss, schedule (done, 2026-11-03)

Ablation, one step at a time (user, 2026-10-28): legacy schedule while adding SEM (P10a) → Siamese (P10b) → the paper's
loss (P10c), then the paper's schedule (P10d). Every run: concat completions (`odg_concat_snaug_s2cc_upTransb_comp`),
completion-only, emb 1024, class rule `relpose_cache` (6,663 train / 1,864 val pairs), seed 777, legacy schedule
(batch 64, AdamW 1e-4 / wd 1e-3, cosine to lr/100 over 25k steps, no shuffle). Leak-free (`completion.frame: world`)
unless marked. DGX jobs 133605 (dgx02; P10a–b) and 134281 (dgx05; P10c–d), one A100 per run.

## Results

Legacy metric = `s2c_total` (best during training, validated every 1k steps) and `model_final`'s legacy `scannet_class`
micro; rotation accuracy from the same report. S2C criteria = the official Scan2CAD per-object criteria (20 cm / 20° / 20 %)
on the 1,864 evaluated S2C-C objects (`s2c_criteria/*`, see P8.md), instance / class mean; S2C box = the CAD-independent
variant on the box (`s2c_box`, P11d.md; from the `--eval-only` re-evaluations). The leaky-frame P10a run is no longer
shown (user, 2026-11-03; it is in `outputs/semcad_legacy_…`).

- **SEM** (`cad_bbox` embeddings, P9): +1.1 legacy final, +0.8 / +2.0 S2C criteria (−center inst / class), +1.5 / +2.9 box.
- **Siamese, separate trunks:** about level with SEM alone on the legacy metric (83.8 vs 84.2 final), better on the S2C
  criteria (+2.0 / +1.7 −center, +5.3 plain), the box criteria (+1.7 / +1.6) and in rotation (93.0 vs 91.5). Twice the
  inference time (two trunks).
- **Siamese, shared trunk (the paper's design):** 4 points below the separate trunks and below the baseline. Single seed
  each; the user judged the gap too large to be seed noise (2026-11-03), so no reseeding. Carried forward: separate trunks.
- **Paper loss (P10c):** no gain: 82.89 vs 83.80 final (best 84.4 vs 84.1), S2C criteria equal (83.4), box 84.9 vs 85.0.
- **Paper schedule (P10d):** worse on every metric (final 81.22, −2.6 vs P10b; S2C criteria −2.5; box −2.3). It trains for
  15,750 instead of 25,000 steps (best validation 82.1 at step 12k) with a tenth of the weight decay.
- **Best model: P10b, separate trunks, with the legacy loss and schedule** (`siamunshared_world_comp_concat_only_emb1024`).
  It is also the model used for CAD retrieval re-ranking (P11d). Of the paper's OCAM changes, SEM and the Siamese CAD
  input help (in the separate-trunk form); the shared trunk, the Chamfer loss and the schedule do not.
- Training time: ~3 h (P10a), ~5.2 h (P10b–c) for 25k steps, ~4 h (P10d).

## Implementation

- `OCAMObjectOnly(ext_emb_size=128)`: legacy `mnkpv3_emb`, SEM embedding concatenated to the pooled feature.
- `OCAMSiamese(shared=…)` (`caoa/models/ocam.py`): object and CAD trunks (`OCAMEncoder`, one module when shared), legacy
  RelPose heads on 4 × emb + SEM. CAD input: 8,192 uniform points per CAD in its own bounding-box frame (centred, longest
  side 1, no annotation, not augmented), cache `cad_points_v1/cad_bbox_8192.npz` (287 MiB, `scripts/build_cad_points.py`).
- Chamfer loss (`caoa/models/pose_losses.py`, user option 1): CD between the CAD's unit-box points placed by the predicted
  box and by the GT box (2,048 points); all three pose components get gradients through it.
- Parameters: 24 M (object-only), 35 M (shared), 56 M (separate). Tests in `tests/test_pose_pipeline.py`.
