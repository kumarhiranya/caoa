## The GT-pose leak (analysis, 2026-10-27)

Scratch scripts and results: `outputs/p8_leak_analysis/` (`leak_analysis.py`, `confirm/leak_confirm.py`; not tracked).
All on the 1,864 val pairs, the legacy S2C-C CAPCM (`s2ccompletion_upTransb1/ckpt-best`) and the P8 `model_final` OCAMs.

**What reaches the completion network.** Legacy maps the instance into the GT box frame
(`(p − c) @ R / max(extents)`), then `infer_completion_odg` centres it on its own mean and divides by its own max
radius. Centre and scale cancel exactly (max difference to the rotation-only input: 4e-14), so **only the GT rotation
R** reaches the network. R is yaw (uniform over 360°) plus a small tilt (median 3.2°, p99 14.5°; 11 pairs > 20°).

**Effect of the completion frame** (completion CDL1 ×1000 vs the GT CAD in the box's metric scale; OCAM legacy
metric, `scannet_class` micro):

| Completion made in | CDL1 | OCAM completion-only (rotation acc.) | OCAM inst+comp |
|---|---|---|---|
| cached legacy completions | 27.13 | 86.75 (97.9) | 81.22 |
| GT box frame, recomputed (seed 0 / 1) | 27.14 / 27.15 | 86.53 / 86.43 (98.1) | 81.44 / 81.49 |
| GT box frame + 45° yaw | 27.19 | 54.40 (61.4) | 81.65 |
| GT box frame + 90° yaw | 27.19 | 11.59 (15.0) | 80.79 |
| GT box frame + 180° yaw | 27.08 | 12.82 (16.0) | 80.79 |
| world frame (no GT) | 28.16 | 34.55 (40.0) | 81.49 |
| random yaw about the world up axis | 28.24 | 31.06 (36.5) | 81.49 |

The completed geometry is equally good in every frame (the network was trained with random yaw), yet completion-only
OCAM collapses; translation accuracy stays ~98% throughout, so the loss is all rotation. Inst+comp is unaffected.

**Confirmation** (1,567 non-symmetric pairs; predicted − GT yaw):
- Completion frame +180°: **95%** of predictions are 180° off; +90°: 78% land 60–120° off; ±45°: pulled partway
  (median offset 18°). The prediction follows the completion frame although the completed shape is in the right place.
- Same geometry, point layout scrambled (one random point per 3%-of-size voxel, 1% jitter, resampled): completion-only
  drops 86.5 → 51.9 (CDL1 27.1 → 31.3); on a scrambled +90° completion only 10% of predictions follow the shift
  (53% unscrambled). On the GT CAD surface itself (perfect geometry): 19.6%, mostly front/back flips.
- Inst+comp stays at 76.8–81.9 in every test.

**Conclusion.** Legacy completion-only OCAM was trained on completions made in the GT frame and then rotated with the
target, so the completion's frame-tied point layout encodes the target rotation; the model learned to read it.
The last two tests also feed inputs unlike the training data, so their drops are partly distribution shift; the
frame-following in the first test is the direct evidence.

## Leak-free fix: `completion_frame: world` (user-approved 2026-10-27)

`caoa/data/pose_completion.py` runs the CAPCM on the instance in the world frame (no GT; the CAPCM's own centring and
scaling are unchanged; legacy's SoftGroup path also completes world-oriented points). The completions are stored in
the same canonical frame as the legacy cache (an exact, GT-using change of storage frame that the pose dataset undoes),
so OCAM training and evaluation are unchanged. Caches `pose_completions_v1/<name>__world` (0.78 GiB each, 4.5–5 min to
build for 8,527 pairs). Test: moving the GT box leaves the world completion unchanged (`test_world_frame_completion_uses_no_gt_pose`).
Configs `configs/pose/world_comp_*.yaml` (otherwise identical to `legacy_comp_*`). DGX job 133605 (dgx02), 2026-10-27/28.

- **The leak was worth ~4 points for completion-only** (86.75 → 82.6–83.1), all in rotation; macro averages drop more
  (80.5 → 69.1 for S2C-C), so rarer classes relied on it more. Inst+comp loses ≤ 1.3 points.
- Leak-free, completion-only still beats inst+comp (82.6–83.1 vs 80.9–81.8) and no completion (73.2). The paper's GT row
  (86.54, completion-only by every indication: all legacy pose configs set `completion_points_only: True`) corresponds
  to ~83 leak-free.
- Under the S2C criteria the leak is worth about as much: completion-only loses 3.7–6.3 points (−center), inst+comp ≤ 1.0.
- Leak-free, the embedding size matters less than with the leak (1024 / 512 / 256: 82.6 / 81.9 / 80.4 final).
- The earlier 34.6% (world completions into the leak-trained model) measured the shortcut, not leak-free performance.
