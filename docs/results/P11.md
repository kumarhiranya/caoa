# P11 — Full pipeline on predicted instances (cached SoftGroup) (2026-11-04)

Plan and decisions: docs/PLAN.md § P11 (user, 2026-11-04). The legacy SoftGroup evaluation (E8) is not reproduced; the
cached SoftGroup val predictions are the instance source. No model is trained here: the leak-free concat CAPCM, the
retrieval embedding (P11d) and the P10b Siamese OCAM (separate trunks) are used as they are.
Code: `caoa/data/softgroup.py`, `caoa/retrieval/pipeline.py` (stage 2, shared with `scripts/rerank_retrieval.py`),
`scripts/run_p11.py`; tests `tests/test_softgroup.py`. Outputs (not tracked): `outputs/p11_softgroup/`
(`results.json`, `matching.json`, `class_synsets.json`), log `outputs/p11_softgroup.log`. DGX job 134281, one A100;
the whole run takes about 15 minutes.

## Instances and matching

312 val scenes with S2C-C annotations, 12,033 predictions of the kept classes (door, window, picture, curtain and shower
curtain excluded), 1,864 S2C-C objects. Matching: point-mask IoU with each object's ScanNet instance, one-to-one,
highest first, IoU ≥ 0.5.

| Confidence ≥ | Capture (S2C-C) | Predictions | Not an S2C-C object | Mean IoU of matches | Detection vs all ScanNet instances: precision / recall / F1 |
|---|---|---|---|---|---|
| 0.0 | 86.4% (1,611) | 12,033 | 10,422 | 0.854 | 22.0 / 80.1 / 0.345 |
| 0.1 | 82.4% (1,535) | 3,523 | 1,988 | 0.862 | 69.5 / 74.3 / 0.718 |
| **0.3** (used below) | **78.0% (1,453)** | 2,816 | 1,363 | 0.870 | **81.5 / 69.6 / 0.751** |
| 0.5 | 73.3% (1,366) | 2,406 | 1,040 | 0.877 | 88.3 / 64.4 / 0.745 |

Detection is scored against the 3,298 ScanNet GT instances of the kept classes, a prediction counting only if it matches
(IoU ≥ 0.5, one-to-one) an instance of its own predicted class. **Most predictions that match no S2C-C object are real
objects**: at 0.3, 2,295 of 2,816 predictions are correct detections, but only 1,453 of them are S2C-C objects; the rest
are furniture Scan2CAD did not align. They are not false positives in the detection sense.

Capture per benchmark category (conf ≥ 0 / 0.1 / 0.3 / 0.5): sofa 96.8 / 94.7 / 92.6 / 91.5; bathtub 90.3 / 91.7 / 91.7 /
87.5; chair 88.3 / 86.6 / 85.1 / 83.1; table 86.6 / 79.4 / 72.7 / 64.2; other 85.3 / 82.8 / 75.9 / 70.7; cabinet 80.5 /
72.3 / 62.3 / 50.3; bookshelf 68.1 / 53.1 / 37.2 / 28.3 (the single trash bin is matched only at conf 0). Predictions
matching no S2C-C object at 0.3 are mostly chairs (407 of 1,188), other furniture (329 of 358) and cabinets (216 of 333).
Unmatched objects are not counted as failures (user, 2026-10-29); unmatched predictions get no pose. Even with no
threshold 13.6% of S2C-C objects are never matched (no prediction reaches IoU 0.5): only a better segmenter recovers them
(bookshelves 68%, cabinets 81% at conf 0).

**Confidence threshold: global 0.3 (user, 2026-11-04).** Detection F1 is flat between 0.2 and 0.5 (0.746–0.752).
Per-class thresholds were tested (scratch `outputs/p11_softgroup/threshold_{analysis,eval}.py`): chosen for the best
per-class detection F1 on one half of the val scenes and scored on the other (2-fold, swapped), they gain up to 1 point of
capture but lose 1.3–2.5 points of precision, and the held-out F1 is lower in both folds (0.750 / 0.741 vs 0.755 / 0.746
for the global 0.3). The chosen thresholds also swing between folds (bed 0.1 vs 0.6, sofa 0.45 vs 0.75, table 0.5 vs
0.25). Train-split SoftGroup predictions, which would allow tuning without val, are not on the DGX.

## Retrieval category for predicted instances

Class-mapped search uses, per SoftGroup class, the fewest ShapeNet synsets that cover 95% of that ScanNet class's
**train** pairs (`class_synsets`; no val information), e.g. chair → chairs; table / desk → tables; sofa → sofas;
cabinet → cabinets, file cabinets, tables, bathtubs, bookshelves; toilet → chairs (ShapeNet has no toilets).
"otherfurniture" and unmapped classes search all synsets.

## Alignment on the 1,453 matched instances (conf ≥ 0.3)

Legacy metric on the box; S2C criteria (unchanged code, −center convention) with the chosen CAD; S2C box = the
CAD-independent variant. Instance / class mean. Re-rank = `sum` score, top-10 candidates, as in P11d.

| Instances | CAD | Legacy | S2C criteria −center | S2C box | Retrieved category correct | CD-L1 to GT CAD |
|---|---|---|---|---|---|---|
| GT (same 1,453 objects) | GT | **86.30** | 85.20 / 76.14 | **86.72 / 78.89** | — | 0 |
| SoftGroup | GT | 83.41 | 83.14 / 74.52 | 85.00 / 77.59 | — | 0 |
| SoftGroup | class-mapped, stage 1 | 80.18 | 35.44 / 26.10 | 83.55 / 75.22 | 91.3 | 55.8 |
| SoftGroup | **class-mapped, re-ranked** | **82.86** | 35.65 / 25.05 | **84.24 / 75.43** | 91.0 | 53.2 |
| SoftGroup | class-mapped, oracle in top-10 | 82.66 | 50.03 / 46.50 | 83.76 / 75.18 | 94.4 | 25.6 |
| SoftGroup | all synsets, stage 1 | 78.32 | 35.72 / 26.30 | 83.21 / 75.20 | 85.8 | 58.4 |
| SoftGroup | all synsets, re-ranked | 82.79 | 35.79 / 25.57 | 84.03 / 75.62 | 87.6 | 54.5 |

- **Segmentation costs about 3 points** on the legacy metric (86.3 → 83.4) and 1.7 / 1.3 on the box criteria, with the GT CAD.
- **Retrieval then costs little:** with re-ranking, the fully automatic pipeline is 0.5 below the GT CAD on the legacy
  metric (82.9 vs 83.4) and 0.8 / 2.2 on the box criteria. The `comp` re-rank score is slightly better on the box here
  (85.00 / 76.60, equal to the GT CAD), `sum` on the legacy metric.
- **Class mapping vs all synsets:** the mapping helps stage 1 (80.2 vs 78.3 legacy; category 91.3 vs 85.8%); after
  re-ranking the two are within 0.2.
- Scan2CAD's own criteria score any retrieved CAD at ~35% (they compare the CAD's native proportions and origin, P11d).
- The matched subset is easier than the full set: GT instances + GT CAD give 86.3 here vs 83.7 on all 1,864 objects.
- Box criteria per category (SoftGroup, class-mapped, re-ranked vs GT CAD): chair 92.4 / 93.8, sofa 88.5 / 89.7,
  cabinet 86.9 / 83.8, bookshelf 78.6 / 85.7, table 75.2 / 70.8, bathtub 57.6 / 63.6, other 48.9 / 55.7.
